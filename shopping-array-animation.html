    💡 배열 핵심 정리

    · 배열은 값을 순서대로 담는 상자 묶음이고, 각 칸의 번호(인덱스)는 0부터 시작합니다.

    · cart[1] → 1번 칸(두 번째 물건), cart.length → 칸의 개수

    · 칸 안에는 { name, price, count } 같은 객체도 넣을 수 있고, cart[0].name처럼 점(.)으로 꺼냅니다.

    · for (const item of cart)는 칸을 처음부터 끝까지 하나씩 꺼내 item에 담아 줍니다.
